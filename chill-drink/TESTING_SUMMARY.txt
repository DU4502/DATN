================================================================================
TROUBLESHOOTING
================================================================================

Problem: SQL errors when running script
  → Check database tables exist
  → Check MySQL version compatibility

Problem: Dashboard shows 0 revenue
  → Check orders have payment_status='paid' OR status='completed'
  → Pending orders don't count

Problem: Ba Đình shows in checkout dropdown
  → Verify branches.status = 0 for Ba Đình
  → Check query filters by status=1

Problem: Charts don't show data
  → Verify orders exist with branch_id
  → Clear cache: php artisan cache:clear
  → Hard refresh browser: Ctrl+Shift+Del

Problem: Numbers not formatted correctly
  → Check browser cache (hard refresh)
  → Verify number_format() in template

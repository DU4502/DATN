IMPORTANT NOTES
================================================================================

1. Revenue Calculation:
   - Only counts when: payment_status='paid' OR status='completed'
   - Pending orders don't count toward revenue
   - This is correct and expected behavior

2. Branch Filtering:
   - Checkout dropdown: WHERE status=1 (active only)
   - Statistics include all branches (for ranking)
   - Inactive branches show 0 data

3. Pickup Order Logic:
   - delivery_type='pickup' → shipping_fee=0
   - branch_id must be set for pickup
   - Address fields not required for pickup

4. Delivery Order Logic:
   - delivery_type='delivery' → shipping_fee calculated
   - branch_id should be null for delivery
   - Address fields required for delivery

5. Data Integrity:
   - Orders must have both delivery_type AND branch_id OR neither
   - Can't have partial data
   - Validation prevents inconsistent states
